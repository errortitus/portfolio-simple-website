# Personal Portfolio Website

A clean personal portfolio and contact page website built using **HTML5** and **CSS**. Designed to showcase web development projects, personal interests, and contact options.

---

**Website Link**: https://errortitus.github.io/portfolio-simple-website/
## Features

* **Portfolio Section**: Introduces background information, personal interests, and key project highlights.
* **Contact Form**: Provides a structured form for user messages along with external profile links.
* **Clean Layout**: Multi-page design connected through internal navigation.
